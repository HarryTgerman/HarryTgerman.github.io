MiningAlpha

Production multi-agent LLM system over a 300+ company evaluation universe.

A hierarchical multi-agent system that performs structured analysis across six analyst dimensions (geology, technical, financial, jurisdiction, management, valuation) for a 300+ company production universe. End-to-end ownership: architecture, agents, multi-LLM routing, retrieval, observability, frontend.

The system exists because eval-driven iteration demanded it: every architectural choice is the answer to a specific measurement. Multi-provider routing, gap-targeted retrieval, reflection-based self-correction, and per-stage capability evaluation aren't aesthetic preferences — they're consequences of "the cheap model degraded accuracy here" and "this stage didn't need retrieval at all."

How it works

  • Hierarchical agent system with specialized analyst agents and knowledge-base-driven capability domains. Each agent runs on a KB slice scoped to its dimension; sub-agents within an agent are context-isolated against domain-specific slices. Agents are discovered dynamically from KB filenames — adding a new analyst dimension is a KB file, not a code change.
  • Multi-LLM routing layer across Anthropic, OpenAI, Google, and DeepSeek foundation models. Eval-driven model selection per pipeline stage: every stage has measured cost and accuracy benchmarks across providers; the routing reflects what won. Cheaper models lose on scoping (entity confusion, junk retrieval); Gemini-class flash models win on extraction; rule-following synthesis goes to GPT-5 Mini; quality-ceiling reasoning goes to Sonnet 4.6. Defaults are documented in the codebase, not folk knowledge.
  • DAG-based agent orchestration with explicit dependency resolution. T0 profiling discovers the entities and management roster. T1 fans out parallel analyst agents per entity (an N-entity company fans out into N×3 per-entity agents + company-level agents). T2 and T3 are synthesis-only — no retrieval, just structured reasoning over upstream agent outputs.
  • Reflection-based self-correction with cache-aware LLM repair: structured-output validation → fence extraction → cache-aware LLM replay → invariant validation → persistence gate. Repair cost ≈1–2% of original call via prompt-cache replay. Same primitives as the OpenClaw harness.
  • Retrieval-augmented agents with gap-targeted retrieval. Agents pre-extract from auto-discovered primary sources (investor presentations, filings). The retrieval layer then queries only for missing fields — 30–50% retrieval reduction per run. The agents pay the price of what they actually need to learn, nothing more.
  • Synthesis-only agents. Valuation and aggregation skip retrieval entirely — they run analyzers directly on prior agent outputs plus injected market data. Saves a full retrieval pass per run and avoids context pollution.
  • Aggregation with structure. The top-of-pipeline aggregator applies stage-conditional weight profiles, gate conditions (hard score caps when critical dimensions fail), and cross-dimension penalties / bonuses. The weights aren't constants in code — they're in a KB, evolvable without redeployment.
  • Inference economics. Per-provider timeouts (300s LLM hard cap), wall-clock retry budgets (600–900s per provider), sparse-mode filter protections (don't filter aggressively when sources are scarce), retrieval-bundle caching with explicit reuse flags. Per-agent unit costs in low cents.
  • Production inference observability. Sentry integration, structured run-summary events with per-run error counts, post-run persistence validation that the database actually reflects what the agents produced.

Surfaces

A Next.js frontend (App Router · Tailwind · shadcn/ui · Recharts) renders the analyst output: a screener with sortable sparklines, company detail pages with score bars and executive summaries, per-entity pages with mini-maps and per-dimension assessments. Multi-currency support.
