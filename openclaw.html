OpenClaw

Proprietary agent harness. Powers every production tenant of deflation.ai.

Harness engineering is the load-bearing layer for production tool-use. The model is a function; the harness is everything around it that has to be true for the output to be safe to act on. OpenClaw is the harness I built for that, and it's the one running my paying customers' bots.

Design principles

  • Repair is cheaper than rejection. Most LLM failures are recoverable. The harness replays the original conversation with a correction prompt appended — because the system prompt + user message are identical to the original call, prompt caching makes repairs cost ≈1–2% of the original call. Rejection is a last resort.
  • Layered correction, not retry. Four distinct repair layers, each with a different cost and a different failure surface: direct parse → markdown-fence extraction → cache-aware LLM self-repair → invariant validation. Non-recursive — layer 4 doesn't call layer 1 with LLM fallback enabled, so the system can't loop.
  • Agent-agnostic primitives. No agent-specific logic in the harness. Repair functions work for any tenant's agent because the contract is at the schema layer.
  • Graceful degradation. If every repair fails, the harness preserves the original result, logs the failure, and continues. It never crashes the bot. A live customer interaction never goes dark.
  • Tool use with bounded retry. Tool dispatch has its own retry budget, scoped credentials, and structured output expectations.
  • Compositionality-aware. The same primitives compose cleanly across product templates and per-tenant leaves. A tax tenant and a real-estate tenant don't run different harnesses — they run the same harness with different KB and skill layers.
  • Observability is first-class. Every layer emits structured trace telemetry. A failure mode that surfaces in production becomes a regression test the next morning.

Where it runs

Every deflation.ai tenant runs OpenClaw. Tenants are isolated as Linux users on Hetzner VPS instances; each holds zero external credentials and talks only to the LLM gateway. The harness also drives MiningAlpha's analyst-tier agents, where the same repair patterns recover malformed structured output from foundation models routed across four providers.
