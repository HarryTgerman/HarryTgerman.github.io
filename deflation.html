How it works

  • Proprietary agent harness (OpenClaw). Tool-augmented LLM execution loop with structured-output enforcement, multi-layer reflection-based self-correction, cache-aware repair, and graceful degradation. Powers every production tenant. Deep-dive.
  • Agent compositionality framework. Inheritance-based agent composition: base primitives → product templates → per-tenant leaves. Customer-specific overrides extend a template via an extends: chain, resolved at deploy time. Product changes propagate to the fleet without forks.
  • LLM gateway with per-tenant inference-budget enforcement. All external API calls (foundation models, SMS, voice, email) proxied through a hardened FastAPI middleware on Railway. Authentication is bearer-token per tenant. Every request debits a prepaid wallet (deterministic Python, not LLM-trusted). require_budget rejects out-of-budget calls at HTTP-protocol level with 402 Payment Required. Tenants hold zero external credentials — prompt injection cannot exfiltrate API keys.
  • Omnichannel agent interfaces. Production-grade integration across email (Resend with DKIM/SPF), SMS and voice (Twilio), and IM (Telegram, per-tenant bots paired via rotating codes from the tenant dashboard). All channels unified through a tenant-scoped behavioral interaction telemetry layer used for monitoring, debugging, and product analytics.
  • Custom Model Context Protocol (MCP) server. Exposes the platform's operator workflows to agent-assisted IDEs — tickets, status, dispatch — so operations themselves run agentically.
  • Continuous agent deployment. Push to main is the release. The gateway shallow-clones the monorepo every 5 min. Deployed tenants run a nightly sync agent that polls per-layer manifest endpoints with their local SHAs; only changed files are fetched and composed. Up-to-date tenants resync in zero bytes and zero LLM tokens.
  • Multi-tenant isolation. Per-tenant Linux users on shared Hetzner VPS, per-tenant scoped credentials for object storage (Cloudflare R2), per-tenant prepaid wallets at the gateway, per-tenant Telegram bot pairings.
  • Production observability. Per-tenant interaction timeline, structured trace telemetry, error capture (Sentry), usage analytics, post-deployment validation.

Surfaces operators see

  • Admin dashboard (Vercel) — assign tenants, email-invite flows with claim-code rotation, Telegram bot registration, manual credit operations.
  • Tenant dashboard (Vercel) — Clerk authentication, Paddle top-ups credited via webhook to the wallet, channel toggles, Telegram pairing UX, messages timeline.
